# Donggeurami Town: website

The support page and the privacy policy of 동그라미타운 (Donggeurami Town),
served by GitHub Pages from this repository's `main` branch.

- `index.html`: the front page
- `support.html`: how to reach us, and how to delete an account
  (`support.html#delete-account` is the link Google Play asks for)
- `privacy.html`: the privacy policy
- `style.css`, `icon.jpg`, `favicon.png`, `apple-touch-icon.png`

Plain HTML and one stylesheet: no build step, no scripts, nothing loaded
from anywhere else. To change a page, edit its file and push.

When the game changes what it keeps about players, change `privacy.html`
and the date at its top with it.
